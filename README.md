# wageRecorder

用于记录上下班打卡、统计工时并按时薪计算工资的微信小程序。数据保存在本地，无需后端。

## 开发

1. 使用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 打开本仓库根目录。
2. 本地校验（可选）：

```bash
npm install
npm test
npm run lint
```

手工回归见 [TEST_CHECKLIST.md](./TEST_CHECKLIST.md)。

图表与表格说明见 [docs/CHARTS.md](./docs/CHARTS.md)。
